# 节点多IP裂变-入口版

把「域名类型」的节点，通过 DoH 解析成多个入口 IP，并把每个 IP 裂变成一个独立节点。与 `../节点多IP裂变` 的区别：**命名前缀按入口 IP 的真实归属**，而非 EDNS 线路名。

## 命名规则

- 用 ip-api.com 查询每个入口 IP 的归属，命名格式为「归属 + IP 第一段」：
  - **国内**（`countryCode=CN`）命中运营商映射 → `电信119 - 原名`（默认不带序号），如深圳电信 `119.x.x.x`
  - **海外**（或国内未命中运营商）→ `新加坡119 - 原名`、`美国36 - 原名`
  - 开启 `seq` 后：`电信119 1 - 原名`
- 运营商英文映射：Tencent→腾讯、Alibaba→阿里、Huawei→华为、Telecom→电信、Unicom→联通、Mobile→移动…
- 同一 IP 去重（一个 IP 只生成一个节点）。
- 地理定位失败时，兜底用 EDNS 线路名（单线路全称，多线路首字，如 `移/电/联`）。
- 无解析结果 / server 本身是 IP 的节点：原样保留。

## 配置

所有可调项集中在脚本**顶部 `CONFIG` 对象**，改配置只看开头即可。其中只有 `edns` / `dohs` / `doh` / `seq` 支持在「脚本操作」参数里运行时覆盖（见下方「参数」），其余项需直接改 `CONFIG`：

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `dohs` | 腾讯/阿里/Cloudflare/Google/Quad9 | DoH 服务器列表，多源轮询；失败自动换源 |
| `resolveRetries` | `3` | 单条解析最多尝试几个 DoH 源（换源重试上限） |
| `resolveBackoffAfter` | `2` | 连续失败达该次数后插入退避等待（0 = 关闭） |
| `resolveBackoffMs` | `800` | 退避基础毫秒，实际等待 = base × 已退避轮次（线性） |
| `type` | `A` | 记录类型：`A` 解析 IPv4，`AAAA` 解析 IPv6 |
| `edns` | 移动/电信/联通 | ECS 线路列表，`name` 为线路标签，`ip` 为对应运营商/地区客户端 IP |
| `seq` | `false` | 命名是否带序号 |
| `keepOriginal` | `false` | 是否额外保留一条原始域名节点 |
| `resolveLimit` | `1` | 解析并发（1 = 逐个串行） |
| `geoipLimit` | `3` | 地理定位并发 |
| `ispMap` | 腾讯/阿里/华为/电信… | 运营商英文→中文映射表 |

## 参数

在「脚本操作」的参数中填写 **键 / 值**，可运行时覆盖以下 4 项（其余 `CONFIG` 项请直接改脚本顶部）：`edns` / `dohs` / `doh` / `seq`。

- 键 `edns`：JSON 数组，每个元素含 `name`（线路标签）和 `ip`（ECS 客户端 IP）

```json
[{"name":"移动","ip":"111.47.229.151"},{"name":"电信","ip":"116.207.181.162"},{"name":"联通","ip":"119.36.124.169"}]
```

- 键 `dohs`：JSON 数组，DoH 服务器列表（优先），如 `["https://doh.pub/dns-query","https://dns.alidns.com/dns-query"]`
- 键 `doh`：单个 DoH 服务器地址（兼容旧写法，会转成单元素 `dohs`），如 `https://223.6.6.6/dns-query`
- 键 `seq`：命名是否带序号，默认关闭（`false`）

**默认值**：不填时用 `CONFIG` 里的默认值。

> 若日志出现 `HTTP/2: headers timeout`，说明 DoH 服务器超时/被限速。脚本会自动换 `dohs` 里的下一个源重试；若经常出现，可多配几个源、或调大 `resolveBackoffMs`。

## 使用方法

1. 打开 Sub-Store → 订阅 → 添加「脚本操作」；
2. 将 `script.js` 内容整体粘贴到脚本框；
3. 按需修改顶部 `CONFIG` 或填写参数；
4. 保存并刷新订阅。

## 可选：保留原始域名节点

把 `CONFIG` 里的 `keepOriginal` 设为 `true`，即可在裂变节点之外额外保留一条原域名节点。

## 注意事项

- 只对**域名**节点裂变，`server` 本身是 IP 的节点原样保留。
- 地理定位用 ip-api.com（免费，有速率限制），已用 `scriptResourceCache` 按 IP 缓存结果（缓存 key 带版本号 `geo:v2:`，且会校验旧格式脏缓存、自动重查）。
- ip-api 用 `lang=zh-CN` 返回中文国家名 + `countryCode`。国内 IP（`CN`）优先按正则映射表显示运营商（腾讯/阿里/华为/电信/移动/联通等）；海外或国内未命中运营商的，显示国家/地区名（如 新加坡、美国）；地理定位完全失败才回退到 EDNS 线路名。
- 解析用「多 DoH 源轮询 + 失败换源重试 + 连续失败线性退避」，缓解单源被限速；解析结果按「域名+类型+线路」缓存（与具体源无关，key 带版本号 `doh:v2:`）。
- 解析和地理定位都做了并发限制，避免一次性打爆接口。
- 若以 `mode=link`（远程链接）方式引入本脚本，可在链接末尾加 `#noCache`，让 Sub-Store 每次都重新拉取脚本内容、不吃脚本下载缓存。
- 裂变会让节点数量成倍增长，注意控制订阅体积。

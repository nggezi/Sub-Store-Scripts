# 节点多IP裂变-入口版

把「域名类型」的节点，通过 DoH 解析成多个入口 IP，并把每个 IP 裂变成一个独立节点。与 `../节点多IP裂变` 的区别：**命名前缀用「运营商 + IP 第一段」**（入口归属），而非 EDNS 线路名。

## 命名规则

- 用 ip-api.com 查询每个入口 IP 的运营商，命名格式为「运营商 + IP 第一段」：
  - 深圳电信 `119.x.x.x` → `电信119 - 原名`（默认不带序号）
  - 开启参数 `seq` 后：`电信119 1 - 原名`
- 运营商英文映射：Tencent→腾讯、Alibaba→阿里、Huawei→华为、Telecom→电信、Unicom→联通、Mobile→移动…
- 同一 IP 去重（一个 IP 只生成一个节点）。
- 地理定位失败时，兜底用 EDNS 线路名（单线路全称，多线路首字，如 `移/电/联`）。
- 无解析结果 / server 本身是 IP 的节点：原样保留。

## 参数

在「脚本操作」的参数中填写 **键 / 值**（可填多组）：

- 键 `edns`：JSON 数组，每个元素含 `name`（线路标签）和 `ip`（ECS 客户端 IP）

```json
[{"name":"移动","ip":"111.47.229.151"},{"name":"电信","ip":"116.207.181.162"},{"name":"联通","ip":"119.36.124.169"}]
```

- 键 `doh`：DoH 服务器地址，默认 `https://doh.pub/dns-query`

```
https://doh.pub/dns-query
```

- 键 `seq`：命名是否带序号，默认关闭（`false`）。如 `true`

```
true
```

**默认值**：不填 `edns` 时内置 移动/电信/联通 三条；不填 `doh` 时用 `https://doh.pub/dns-query`；不填 `seq` 时**不带序号**。

> 若日志出现 `HTTP/2: headers timeout`，说明 DoH 服务器超时/被限速，换个 DoH 即可（如 `https://doh.pub/dns-query`、`https://1.1.1.1/dns-query`）。

## 并发说明

脚本**逐个节点串行**解析（单节点内 3 条线路并发），地理定位限制 3 并发。避免一次性打爆 DoH 导致超时。

## 使用方法

1. 打开 Sub-Store → 订阅 → 添加「脚本操作」；
2. 将 `script.js` 内容整体粘贴到脚本框；
3. 按需填写参数（键 `edns`，值 JSON 数组；不填用默认）；
4. 保存并刷新订阅。

## 可选：保留原始域名节点

如需在裂变节点之外额外保留一条原域名节点，取消 `script.js` 末尾注释：

```js
// list.push({ ...p, name: `原始 - ${p.name}`, server: p._domain });
```

## 注意事项

- 只对**域名**节点裂变，`server` 本身是 IP 的节点原样保留。
- 地理定位用 ip-api.com（免费，有速率限制），已用 `scriptResourceCache` 按 IP 缓存结果。
- ip-api 返回英文 ISP，脚本内建正则映射表转中文（腾讯/阿里/华为/电信/移动/联通等）；未匹配的运营商会被忽略，回退到 EDNS 线路名。
- 裂变会让节点数量成倍增长，注意控制订阅体积。

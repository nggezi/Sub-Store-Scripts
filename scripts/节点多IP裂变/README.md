# 节点多IP裂变

把「域名类型」的节点，通过 DoH 解析成多个入口 IP，并把每个 IP 裂变成一个独立节点。一个脚本即可完成，无需像官方那样串联两个操作。

## 原理

Sub-Store 的脚本操作本身支持 `async`，因此可以在同一个 `operator` 里直接 `await ProxyUtils.doh`：

1. 遍历所有节点，跳过本身就是 IP 的节点；
2. 对域名节点发起 DoH 解析，按需注入 EDNS Client Subnet（ECS）；
3. 把解析出的每个 IP 复制成一个新节点（仅替换 `server` 与 `name`）。

官方方案拆成「解析脚本 + 裂变脚本」两步，是因为第一步用来替换内置的「域名解析」步骤、只负责把结果挂到 `server` 上；本脚本把两步合并，效果一致且更省事。

## 两种模式

| 模式 | 配置 | 效果 |
| --- | --- | --- |
| 多线路 | `multiLine: true` | 对联通/电信/移动分别注入不同 ECS，解析出对应线路入口，节点名带线路名，如 `联通1 - 香港01` |
| 纯裂变 | `multiLine: false` | 不做 ECS，解析出该域名的全部 IP 逐个裂变，节点名如 `1 - 香港01` |

## 参数说明

配置位于脚本顶部 `CONFIG` 对象：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `doh` | `https://223.6.6.6/dns-query` | DoH 服务器。阿里/腾讯公共 DoH 易限速，可换成自建或其它 DoH |
| `type` | `A` | 记录类型：`A` 解析 IPv4，`AAAA` 解析 IPv6 |
| `multiLine` | `true` | 是否启用多线路模式 |
| `edns` | 联通/电信/移动 | ECS 列表，`name` 用于节点命名，`ip` 为对应运营商/地区客户端 IP |
| `keepOriginal` | `false` | 是否额外保留一个原始域名节点 |
| `maxIpPerLine` | `5` | 每条线路最多裂变几个 IP，`0` 表示不限 |
| `dedupe` | `true` | 是否按「线路名+序号+IP」去重 |

## 使用方法

1. 打开 Sub-Store → 订阅 → 添加「脚本操作」；
2. 将 `script.js` 内容整体粘贴到脚本框（本次脚本不需要额外参数）；
3. 按需修改顶部 `CONFIG`；
4. 保存并刷新订阅。

## 注意事项

- 只对**域名**节点裂变，`server` 本身是 IP 的节点原样保留。
- 无解析结果时会保留原节点，不会丢节点。
- 已用 `scriptResourceCache` 按 `(域名 + 线路)` 缓存解析结果，降低 DoH 限速风险。
- 裂变会让节点数量成倍增长，建议用 `maxIpPerLine` 控制上限。
- EDNS Client Subnet 本质是声明「请求方所在网段」，用于拿到就近/同线路入口，请按实际需求填写。
